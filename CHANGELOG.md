# Changelog

## 4.0.0 — First portfolio release

- Responsive task dashboard for mobile and desktop sizes.
- Local-first task storage with SharedPreferencesAsync.
- Task create/edit/complete/delete workflows.
- Due dates, category and priority filters, search, and completed-task cleanup.
- Sample data, progress metrics, controller/model/widget test coverage.
- CI workflow for format, analysis and unit/widget tests.

## V4.0.1 — Responsive sidebar fix

- Made the desktop sidebar vertically scrollable to prevent bottom overflow on shorter browser windows.
- Kept the task navigation and local-only data model unchanged.
